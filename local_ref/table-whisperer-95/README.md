# Table Harmony

Create a UI UX for restaurant table listing. It should show if it currently being occupied or not, should have an option to print the QR for the table. And when the table is clicked, it should show the orders from that table, total cost for the orders and have an option to pay for that+ print the receipt.



The design should be fabulous
